# 💜 HERCLUB - Propuesta para Inversores

Una propuesta interactiva profesional para presentar HERCLUB, la comunidad femenina más exclusiva del mundo digital.

## 🌸 Sobre HERCLUB

HERCLUB es una app exclusiva para mujeres donde pueden hacer amistades reales, asistir a eventos, viajar, cuidar su bienestar mental, recibir coaching, acceder a psicólogas reales o con IA, obtener asesoramiento de imagen, entrenar, hacer su carta astral con IA y mucho más.

Una comunidad cerrada por invitación que fusiona Tinder (para amistad), Meetup, Calm, Airbnb y Masterclass bajo una identidad femenina moderna y elegante.

## 🚀 Características de la Propuesta

Esta aplicación web interactiva incluye:

- ✨ Presentación tipo pitch deck con 12 secciones navegables
- 🎨 Diseño moderno con los colores de marca de HERCLUB
- 🔄 Animaciones suaves y transiciones elegantes
- 📱 Diseño completamente responsivo
- 🎯 Navegación intuitiva entre secciones
- 💎 Componentes visuales impactantes

### Secciones Incluidas

1. **Hero** - Introducción y visión del proyecto
2. **El Problema** - Análisis del problema de mercado
3. **La Solución** - Propuesta de valor de HERCLUB
4. **Funcionalidades** - 13 funcionalidades principales
5. **Mercado** - Oportunidad de mercado y target
6. **Modelo de Negocio** - Fuentes de ingreso y pricing
7. **Inversión** - Desglose detallado del uso de capital
8. **Roadmap** - Plan de desarrollo de 6 meses
9. **Proyección Financiera** - Crecimiento proyectado a 3 años
10. **Branding** - Identidad de marca y paleta de colores
11. **Equipo** - Perfil del equipo fundador
12. **Llamada a la Acción** - Invitación a inversores

## 🛠️ Tecnologías Utilizadas

- **React 18** - Framework principal
- **Vite** - Build tool y dev server
- **Framer Motion** - Animaciones y transiciones
- **Lucide React** - Iconos modernos
- **CSS3** - Estilos personalizados

## 📦 Instalación

### Prerrequisitos

- Node.js 16+ y npm instalados

### Pasos de Instalación

1. **Instalar dependencias**

```bash
npm install
```

2. **Iniciar el servidor de desarrollo**

```bash
npm run dev
```

3. **Abrir en el navegador**

La aplicación se abrirá automáticamente en `http://localhost:5173`

## 🏗️ Scripts Disponibles

- `npm run dev` - Inicia el servidor de desarrollo
- `npm run build` - Genera la versión de producción
- `npm run preview` - Previsualiza la build de producción
